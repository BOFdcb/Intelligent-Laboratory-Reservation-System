# 实验室使用规则（总则）

1. 实验室面向本校在册学生开放，使用需提前在预约系统提交申请，经管理员审核通过后方可使用。
2. 开放时段：各实验室具体开放时间以系统公示为准，一般为每日 8:00 - 22:00。
3. 每次预约时长最短 30 分钟，最长不超过 4 小时；同一时段不可重复预约同一实验室。
4. 预约人数不得超过实验室人数上限。
5. 实验室内禁止饮食、吸烟、大声喧哗。
6. 使用设备需按操作规程进行，实验结束后关闭电源、整理工位。
7. 如遇设备故障，请立即停止使用并向管理员报告，不得自行拆修。
8. 违反规则累计 3 次者，将暂停预约资格一周。

# 预约与取消须知

- 预约提交后进入"待审核"状态，管理员将在 24 小时内完成审核。
- 待审核与已通过的预约均可由本人取消；已使用的预约不可取消。
- 请至少提前 30 分钟取消预约，临时爽约将影响信用记录。
- 审核被驳回时可查看驳回原因，修改后可重新提交。

# 安全须知

- 进入实验室请遵守用电安全规范，禁止私拉电线。
- 贵重物品请随身携带，离室时锁好门窗。
- 发生紧急情况请按墙上的疏散指示撤离，并拨打校园保卫处电话。
